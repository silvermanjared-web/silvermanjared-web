# Marketing Operations Director

I design and build automation systems that replace manual marketing workflows with reliable, maintainable infrastructure. Most of my work sits at the intersection of marketing strategy and software engineering — turning operational problems into code.

## What I Build

- **Marketing Intelligence** — automation and reporting that surfaces signal without requiring daily manual review
- **Execution Tooling** — audit and optimization systems that keep campaigns and data pipelines running clean
- **Playbooks** — repeatable systems at scale for taxonomy governance, data validation, and diagnostics

## Stack

Python | Google Ads API | Gmail API | SQL | macOS automation | Claude API

## Approach

- **Diagnostic first** — measure before acting
- **Systems over heroics** — build once, run reliably
- **Signal over noise** — score and filter, don't just report
- **Config over code** — workflows should be data, not logic
