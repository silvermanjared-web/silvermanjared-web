# Asset Inventory

Use this file to track logos, fonts, imagery, icons, and source files added to the design system.

## Logos

Place logo files in:

- `assets/logos/`

Recommended formats:

- SVG for web and scalable usage
- PNG for fallback usage
- PDF or EPS only when needed for print/vendor workflows

Inventory:

| Asset | File | Usage | Notes |
|---|---|---|---|
| Primary logo | Pending | Header, footer, brand moments | Add official file |
| Reversed logo | Pending | Dark backgrounds | Add official file |
| Icon mark | Pending | Favicon, app icon, social | Add official file |

## Fonts

Place licensed font files in:

- `assets/fonts/`

Do not commit fonts unless licensing permits repository storage and redistribution.

Inventory:

| Font | File | Weight | License notes |
|---|---|---|---|
| Inter fallback | External/system | 400-700 | Placeholder system stack |

## Icons

Place icons in:

- `assets/icons/`

Recommended format: SVG.

## Source files

Place Figma exports, `.fig` files, or other local source files in:

- `assets/source/`

Important: if using a `.fig` file, parse locally when possible and avoid uploading sensitive design files to third-party tools unless approved.
