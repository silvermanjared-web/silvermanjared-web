# Brand Design System

> Archived reference folder. This is not the current public design-system starter source of truth.

This folder was an early front-end focused brand design-system reference inside the profile README repository. It is retained for historical context only.

For the current standalone public starter system, use the `brand-design-system-starter` repository.

## Current source-of-truth guidance

- Use `brand-design-system-starter` for reusable tokens, foundations, component specs, generated CSS variables, and AI-assisted front-end handoff.
- Use `brand-context-system` as the intake layer for brand rules, voice, code references, Figma notes, assets, examples, and prompts.
- Treat this embedded folder as an archived reference, not as the canonical palette or implementation layer.

The token palette here may differ from the standalone starter. That difference is historical context, not an active design-system fork.
